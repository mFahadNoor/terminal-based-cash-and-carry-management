1. **Inventory Management Module**: This module allows the store Manager to manage the store's inventory levels and track the movement of goods. The module is designed to streamline inventory management processes, such as product ordering, product taking, and price management. Some of the key functions included in this module are:

   - **Products Ordering**: This function allows store employees to place orders for new products when inventory levels fall below a certain threshold (e.g., when a product's inventory is less than 100 items). Store employees can place orders for that product from suitable suppliers who provide such products.
   - **Products Take**: This function allows store employees to perform regular product counts to ensure that inventory levels match the system's records. Whenever a product is taken from the supplier, the product quantity and price are updated in the inventory.
   - **Price Management**: This function allows store employees to set and update prices for the store's products. The system can manage complex pricing structures, such as volume discounts, promotional pricing, or dynamic pricing based on market conditions (for example, a 50% discount on all products during Ramadan). At least five pricing strategies should be implemented, including various promotional offers.

2. **Point of Sale (POS) Module**: This module provides a seamless checkout experience for customers while enabling store salespeople to process transactions efficiently. Some of the key functions included in this module are:

   - **Add to Cart**: This function allows store salespeople to add items to the cart for customers. The system handles a high volume of transactions and provides real-time updates on stock availability for each product.
   - **Apply Discounts**: This function allows store employees to apply discounts to customers' purchases based on promotions or other factors. The system can manage complex discount structures, such as buy-one-get-one-free or percentage discounts.
   - **Issue Refunds**: This function allows store employees to issue refunds to customers for returned items. The system processes refunds quickly and accurately while ensuring that inventory levels are updated accordingly.

3. **Reporting Module**: This module provides store management with data on sales, inventory levels, and profits. It generates custom reports based on predefined parameters or ad hoc queries. Some of the key functions included in this module are:

   - **Sales Reports**: This function generates reports based on sales data, such as sales by product, sales by day, or sales by customer. The system provides real-time data on sales performance.
   - **Inventory Reports**: This function generates reports on inventory levels, such as inventory by product, inventory by location, or inventory by supplier. The system provides real-time data on inventory performance.
   - **Profit Reports**: This function generates reports on profits, such as profits by product, profits by day, or profits by customer. The system provides real-time data on profit performance.

### Menu-Driven System:
The system is menu-driven. Upon running the program, there are two options at the start:

- **Press 1** to continue as Manager
- **Press 2** to continue as Store Salesman
- **Press 3** to exit

After selecting either option 1 or 2, a further menu appears to perform the different functionalities for Manager or Salesman, as outlined above.
